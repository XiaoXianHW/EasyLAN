# Fabric 历史故障回归范围

## 版本和证据边界

原始失败记录针对 2026-08-23/24 的 v1.6a JAR，不能直接当作当前源码仍失败的证据。
本分支基线 `6e3effa` 已有针对性生产修复。历史修复保留，并新增回归守卫和测试指导。后续实机发现的服务器初始化崩溃
另有生产修复，见文末；不把既有修复冒充本次新增修复。本文件不是实机通过报告。

本分支必须分别验证：1.20.6、1.21.1、1.21.5、1.21.11。共享源码不代表各版本 API 和运行时兼容性相同。

## 离线源码守卫

运行 `python3 -m unittest discover -s tests -v`。
这些检查保证 MOTD 走可重映射的强类型调用、发布 LAN 后重新应用设置；现代版本还检查
创建世界页面没有注入按钮，以及每个输入框只注册一次、没有手工重复转发输入事件。
这类测试不能证明真实焦点、渲染、输入、混淆重映射或网络服务可用；发布前必须完成下列实机测试。

## 实机回归步骤和判定

每个版本使用独立游戏目录，并记录 Minecraft、Fabric Loader/API、JAR SHA-256、
测试提交、Java、窗口尺寸和 GUI 缩放。加载生产 remapped JAR 测试，不能仅用开发环境替代。

1. 启动到主菜单无崩溃；单人存档选择页左上角 EasyLAN 入口存在。无存档时先创建一个再返回。
2. 创建世界页面无 EasyLAN 按钮覆盖游戏模式页签；检查默认及放大 GUI 缩放、窗口大小改变，
   创建页返回/重进和取消均不叠加控件。
3. 从存档选择页进入设置：背景和控件不叠加。逐个开关来回切换；关闭 online mode。
4. 点击 MOTD/info 输入框，输入唯一标识 `FABRIC-1.20.6-42`；
   验证逐字输入一次只出现一个字符、Backspace/Delete、左右键、Home/End、选择并替换、粘贴。
   保存，退出设置，再进入并加载配置，内容与开关保持一致。切到另一控件再返回仍可编辑。
5. 进入单人世界，打开 LAN 页面：端口填一个本机可用值如 25566，最大人数填 12。
   先清空两个框，各输入单个数字 `2`，确认仅出现 `2`；随后逐位输入、删除、全选替换，
   在两框间切换焦点并重复打开/取消，确认没有重复字符或失去编辑能力。
6. 检查端口边界 99/100/65535/65536、已占用端口、字母和空值；人数 1/2/500000/500001、
   字母和空值。无效值不能启动，空值应使用默认行为，不产生解析异常。
7. 恢复可用端口 25566、人数 12，点击 Start LAN World 一次。
   聊天输出 customport/maxplayer 与输入一致，online mode=false；开启 HttpAPI 和 LAN 输出时均正常。
8. 请求 `http://127.0.0.1:28960/status` 与 `/playerlist`，
   验证版本、存档主人、端口、最大人数、在线玩家及 MOTD 自定义标识。
   对 MOTD 历史故障，HTTP status.motd 是必须记录的断言；另记录多人列表描述，勿混淆两者。
9. 退出到主菜单无崩溃，两接口拒绝连接；再次进入并开放 LAN，确认端口可重新绑定且数据更新，
   不重复聊天输出、不保留上次世界玩家。关闭 API 后重复，确认服务不启动。

## 历史缺陷重点

- 1.16.4/1.16.5：MOTD 自定义内容，重点验证生产环境重映射后的强类型设置调用
- 1.20.6：创建世界控件重叠、MOTD
- 1.21.1：MOTD/info 无法编辑，LAN 两输入框单字符变双字符
- 1.21.5：创建世界控件重叠、MOTD/info 无法编辑、LAN 重复字符
- 1.21.11：创建世界控件重叠、MOTD；同时覆盖新版输入事件 API

本分支之外的历史通过版本也应在整套发布前按用户原流程回归；不因本分支源码守卫通过而
标记其他版本为通过。保留每个版本的截图、latest.log、HTTP 响应和退出后的拒绝连接结果。

## 新增实机发现：服务器初始化时序

Fabric1.21.5 实机在首次创建世界时崩溃：SERVER_STARTING 阶段调用 getGameRules()，
其 overworld 尚为空。本次将服务器规则应用移到 SERVER_STARTED；命令注册仍保留在
SERVER_STARTING，配置读取仍保留在模组初始化。发布 LAN 后仍会重新应用规则。
同生命周期调用的相关 Fabric 家族一并改为此顺序。各版本必须验证首次创建世界、
读取已有存档、退出再进，以及生成规则、MOTD、online mode 与命令是否生效。
